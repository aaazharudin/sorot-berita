You are a senior frontend engineer and UI/UX designer.

Create a modern, premium news website using Next.js (App Router) and Tailwind CSS.

IMPORTANT:
The design must feel like a high-quality editorial platform (similar to Apple News, Medium, or Bloomberg) — NOT a generic template.

---

🎨 DESIGN SYSTEM (VERY IMPORTANT)

Use a clean, editorial color palette:

* Primary: Black / Dark Gray (#0F172A or #111827)
* Background: White (#FFFFFF) and Light Gray (#F9FAFB)
* Accent: Blue (#2563EB) or Emerald (#10B981) — use minimally
* Text:

  * Headline: font-bold, dark
  * Body: neutral gray (#6B7280)

DO NOT use purple gradients or flashy colors.

Style should be:

* Minimal
* Elegant
* Spacious
* Professional
* High readability

---

📐 LAYOUT STRUCTURE

1. NAVBAR:

* Left: Logo "ZONA"
* Center: Menu (Home active)
* Right:

  * Search icon
  * Dark mode toggle
  * Login button (outline or subtle fill, NOT gradient)

Sticky navbar with subtle border-bottom.

---

2. TRENDING TAGS:

* Horizontal scroll
* Rounded pill tags
* Light gray background
* Hover → darker text

---

3. HERO SECTION:

LEFT (70% width):

* Large featured image
* Dark gradient overlay
* Category badge (small, uppercase)
* BIG headline (very bold, large text)
* Short description
* Author + time

RIGHT (30% width):

* 2 stacked cards
* Clean card design (no heavy gradient)
* Subtle shadow
* Image + title overlay or below

---

4. MAIN CONTENT:

LEFT:

* "Latest News"
* Vertical list
* Each item:

  * Image (rounded-lg)
  * Category label (small, uppercase, accent color)
  * Title (bold)
  * Description
  * Meta (author, time)

RIGHT SIDEBAR:

A. Popular Today

* Clean numbered list (no heavy background)

B. Topics

* Tag buttons (outline style)

C. Newsletter

* Minimal card
* Input + button
* Soft border, no gradient

---

5. FOOTER:

* Minimal, 3–4 columns
* Small text
* Neutral colors

---

💡 UI DETAILS

* Use spacing generously (p-6, gap-6)
* Rounded-xl elements
* Soft shadows (shadow-sm)
* Smooth hover effects:

  * scale slightly
  * subtle shadow increase
* Typography hierarchy is VERY IMPORTANT

---

⚙️ TECH REQUIREMENTS

* Next.js 14+ (App Router)

* Tailwind CSS

* Components:

  * Navbar
  * HeroSection
  * NewsCard
  * Sidebar
  * Footer

* Use mock data

* Fully responsive

---

✨ BONUS (IMPORTANT)

* Add dark mode (class-based Tailwind)
* Add loading skeleton
* Use lucide-react icons
* Use grid layout (not flex everywhere)

---

🎯 FINAL GOAL

The result should look like a real professional news website — clean, fast, and trustworthy.

Avoid anything that looks like a template or landing page.

Focus on readability and hierarchy.
